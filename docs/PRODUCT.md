# 📋 ClassFlow — خطة المنتج (Product Plan)

## 1. المشكلة

المدارس في موريتانيا والعالم العربي تعاني من:
- دفاتر ورقية (غياب، دروس، نقاط، أقساط) — تضيع، تتمزق، تتلف
- وقت المهدر: الأستاذ يملأ دفاتر، الإدارة تراجعها، الحسابات يدوية
- **ثقة أولياء الأمور مهزوزة** — لا يوجد تواصل فوري، يعرفون بالغياب بعد أيام
- لا توجد تقارير دقيقة وفورية

## 2. الحل — ClassFlow

منصة رقمنة **الدفاتر اليومية** للمدرسة:
- **دفتر الغياب الرقمي** ← الأستاذ يفتح التطبيق → يسجل الغياب ← ولي الأمر يستقبل إشعاراً فورياً
- **دفتر الدروس الرقمي** ← الأستاذ يسجل عنوان الحصة والواجب ← الإدارة تتابع
- **دفتر النقاط الرقمي** ← الأستاذ يدخل النتائج ← النظام يحسب المعدلات والترتيب ← طباعة الكشوف
- **دفتر الأقساط الرقمي** ← تسجيل المدفوعات ← المتأخرات ← الوصولات ← التذكير التلقائي
- **حضور الأساتذة** ← التطبيق يسجل وقت دخول الأستاذ تلقائياً ← لا مزيد من دفاتر الحضور

## 3. الخدمات (Service Catalog)

### الخدمات الأساسية (المشتركة في الاشتراك):

| الخدمة | لمن؟ | ماذا تقدم؟ |
|--------|------|------------|
| **دفتر الغياب** | الأستاذ + ولي الأمر | تسجيل الغياب + إشعار فوري للواتساب |
| **دفتر الدروس** | الأستاذ + الإدارة | تسجيل يومي لعناوين الدروس والواجبات |
| **دفتر النقاط** | الأستاذ + الإدارة | إدخال نتائج + حساب تلقائي للمعدلات والرتب |
| **دفتر الأقساط** | المحاسب + ولي الأمر | تتبع المدفوعات + وصلات + تذكير بالمتأخرات |
| **حضور الأساتذة** | الإدارة | تسجيل وقت حضور وانصراف كل أستاذ |
| **إدارة الطلاب** | الإدارة | تسجيل، نقل، فصل، تعديل بيانات |
| **إدارة المدرسين** | الإدارة | تعاقد، فصل، تعديل، توزيع على الأقسام |
| **التقارير** | الإدارة + المحاسب | كشوف النقاط، إحصائيات الغياب، تقارير مالية PDF |
| **الإشعارات** | ولي الأمر | إشعارات واتساب: غياب، نتائج، تذكير بالرسوم |

### الخدمات المميزة (إضافية أو مرحلة لاحقة):

| الخدمة | الوصف |
|--------|-------|
| **الجداول المدرسية** | بناء جدول الحصص drag & drop |
| **المكتبة الرقمية** | مشاركة الدروس والملفات مع الطلاب |
| **التواصل المباشر** | دردشة بين الأستاذ وولي الأمر |
| **تطبيق ولي الأمر** | تطبيق مستقل للمتابعة |

## 4. من يشتري؟ (Target Market)

| الزبون | المشكلة عنده | لماذا يشتري ClassFlow؟ |
|--------|-------------|----------------------|
| **مدير المدرسة** | لا يرى صورة واضحة عن مدرسته | لوحة تحكم دقيقة، تقارير فورية، متابعة كل شيء |
| **الأستاذ** | يضيع ساعات في الملء الورقي والحساب | 5 دقائق عمل يومياً، لا حسابات يدوية |
| **ولي الأمر** | لا يعرف أخبار ابنه إلا بعد فوات الأوان | إشعار فوري بكل شيء (غياب، نتائج، رسوم) |
| **المحاسب** | أخطاء في الحسابات، دفاتر ممزقة | نظام دقيق، وصلات تلقائية، تذكير آلي |

## 5. لماذا تختار المدرسة ClassFlow؟

1. **بساطة** — لا تعقيد ERPs الكبيرة، فقط ما تحتاجه المدرسة يومياً
2. **سرعة** — الأستاذ يعمل من هاتفه في دقائق
3. **تواصل فوري** — ولي الأمر يعرف بالغياب حال حدوثه
4. **لا حسابات يدوية** — النظام يحسب كل شيء
5. **متعدد اللغات** — عربي + فرنسي (مناسب لموريتانيا)
6. **سعر مناسب** — اشتراك شهري بسيط بدلاً من شراء نظام كامل

## 7. MVP (الحد الأدنى للإطلاق)

الخدمات التي يجب أن تعمل **قبل بيع المنتج**:

1. ✅ تسجيل دخول + أدوار
2. ✅ دفتر الغياب + إشعارات
3. ✅ دفتر الدروس
4. ✅ دفتر النقاط + حساب المعدلات
5. ❌ دفتر الأقساط ← **Phase 3**
6. ❌ إدارة المدرسين (CRUD) ← **Phase 1**
7. ❌ إدارة الطلاب (CRUD) ← **Phase 1**
8. ❌ إدارة الأقسام ← **Phase 1**
