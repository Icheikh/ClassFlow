# 📘 ClassFlow — وثيقة تصميم النظام الكاملة

## 1. الأدوار وصلاحياتها (Role Matrix)

| الدور | الوصف | المهام |
|-------|-------|--------|
| **SUPER_ADMIN** | مالك المنصة | إدارة المدارس، الاشتراكات، الدعم الفني |
| **SCHOOL_ADMIN** | مدير المدرسة | كل صلاحيات المدرسة، إدارة الموظفين والطلاب، اعتماد النتائج |
| **DIRECTOR** | مدير الدراسات | إدارة المدرسين، الجدول، المنهج، الإشراف التربوي |
| **SUPERVISOR** | مراقب | متابعة الغياب، الحضور، المتابعة اليومية |
| **ACCOUNTANT** | محاسب | الأقساط، الدفعات، المتأخرات، الوصولات، التقارير المالية |
| **TEACHER** | أستاذ | أقسامه ومواده فقط: غياب، دروس، نقاط |
| **PARENT** | ولي أمر | متابعة أبنائه فقط: الغياب، النتائج، الإشعارات |

## 2. Feature List (حسب كل دور)

### SUPER_ADMIN
- [ ] لوحة تحكم المنصة (عدد المدارس، المستخدمين، الإيرادات)
- [ ] إدارة المدارس (إضافة، تعطيل، حذف)
- [ ] إدارة الاشتراكات والخطط
- [ ] إدارة المستخدمين العامين
- [ ] تقارير المنصة

### SCHOOL_ADMIN
- [ ] لوحة تحكم المدرسة (إحصائيات)
- [ ] **إدارة المدرسين** ← إضافة، تعديل، تعليق، فصل
- [ ] **إدارة الطلاب** ← تسجيل، تعديل، نقل قسم، فصل
- [ ] **إدارة الأقسام** ← إضافة، تعديل، دمج
- [ ] **إدارة المواد** ← إضافة، تعديل، توزيع على الأقسام
- [ ] **إدارة الموظفين** ← مدير دروس، مراقب، محاسب (إضافة/تعديل/فصل)
- [ ] **توزيع المدرسين** ← تعيين مدرس لقسم/مادة
- [ ] **اعتماد النتائج** ← الموافقة على كشوف النقاط النهائية
- [ ] **التقارير** ← كشوف متنوعة PDF
- [ ] إعدادات المدرسة (الاسم، الشعار، العنوان...)
- [ ] الاطلاع الكامل على: الغياب، الدروس، النقاط، المالية

### DIRECTOR (مدير الدراسات)
- [ ] لوحة تحكم الدراسات
- [ ] الإشراف على المدرسين (حضورهم، أدائهم)
- [ ] متابعة الدروس المسجلة
- [ ] متابعة الغياب
- [ ] اقتراح تعديلات على الجدول

### SUPERVISOR (مراقب)
- [ ] متابعة الغياب اليومي
- [ ] متابعة حضور المدرسين
- [ ] تقارير يومية

### ACCOUNTANT (محاسب)
- [ ] إدارة الرسوم الدراسية
- [ ] تسجيل الدفعات
- [ ] طباعة الوصولات
- [ ] متابعة المتأخرات
- [ ] إرسال تذكير بالدفع
- [ ] التقارير المالية

### TEACHER (أستاذ)
- [ ] **دفتر الغياب** ← تسجيل غياب → إشعار فوري لولي الأمر
- [ ] **دفتر الدروس** ← عنوان الدرس، وصف، واجب، ملاحظات
- [ ] **دفتر النقاط** ← إدخال نتائج → النظام يحسب المعدلات
- [ ] **بصمة الحضور** ← تسجيل حضوره اليومي تلقائياً عند الدخول

### PARENT (ولي أمر)
- [ ] متابعة غياب أبنائه (إشعارات واتساب)
- [ ] متابعة النتائج
- [ ] جدول الأبناء

## 3. خريطة الصفحات (Route Map)

```
/                                   ← تسجيل الدخول
├── /dashboard                      ← لوحة المدير (SCHOOL_ADMIN)
├── /admin                          ← لوحة المنصة (SUPER_ADMIN)
│
├── /school/                        ← إدارة المدرسة (SCHOOL_ADMIN)
│   ├── /teachers                   ← إدارة المدرسين ← CRUD كامل
│   ├── /students                   ← إدارة الطلاب ← CRUD كامل
│   ├── /classrooms                 ← إدارة الأقسام + توزيع المواد
│   ├── /subjects                   ← إدارة المواد
│   ├── /staff                      ← إدارة الموظفين (مدير دروس + مراقب + محاسب)
│   └── /settings                   ← إعدادات المدرسة
│
├── /teacher/                       ← واجهة الأستاذ (TEACHER)
│   ├── /attendance                 ← دفتر الغياب
│   ├── /lessons                    ← دفتر الدروس
│   └── /grades                     ← دفتر النقاط
│
├── /finance/                       ← المالية (ACCOUNTANT)
│   ├── /fees                       ← الرسوم
│   ├── /payments                   ← الدفعات
│   ├── /receipts                   ← الوصولات
│   └── /reports                    ← التقارير
│
├── /supervision/                   ← المراقبة (SUPERVISOR + DIRECTOR)
│   ├── /attendance                 ← متابعة الغياب
│   ├── /teachers                   ← حضور المدرسين
│   └── /reports                    ← التقارير
│
└── /parent/                        ← ولي الأمر (PARENT)
    ├── /attendance                 ← غياب أبنائي
    ├── /grades                     ← نتائج أبنائي
    └── /notifications              ← الإشعارات
```
